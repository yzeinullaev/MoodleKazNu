# ИИ-проверка диссертации DBA (Farabi IBS, 2026)

Основа: *Методические указания по написанию, оформлению и представлению докторских диссертаций DBA с учётом ИИ*.

## Оформление (автоматически из DOCX)

| Параметр | Требование |
|----------|------------|
| Формат | A4 |
| Шрифт | Times New Roman, 14 pt |
| Интервал | одинарный (1.0) |
| Поля | левое 30 мм, правое 15 мм, верх/низ 20 мм |
| Объём | 70–90 страниц основного текста |

## Структура и содержание (эвристика + OpenAI)

- Титульный лист, реферат, содержание, введение, 3 главы, заключение, источники
- Элементы введения (актуальность, цель, задачи, объект, предмет и др.)
- Раскрытие использования ИИ
- **Приложение 11** — чек-лист самопроверки (JSON от OpenAI)
